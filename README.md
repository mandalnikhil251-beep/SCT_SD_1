# Temperature Converter

A simple and responsive web application that converts temperatures between Celsius, Fahrenheit, and Kelvin.

## Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Input validation
- Kelvin below 0 K validation
- Swap temperature units
- Clear button
- Enter key support
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Enter a temperature.
5. Select the source and target units.
6. Click Convert.

## Conversion Formulas

### Celsius to Fahrenheit

F = (C × 9/5) + 32

### Fahrenheit to Celsius

C = (F - 32) × 5/9

### Celsius to Kelvin

K = C + 273.15

### Kelvin to Celsius

C = K - 273.15
